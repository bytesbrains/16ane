# 16ane के साथ शुरुआत

[English](ONBOARDING.md) · **हिन्दी**

> [!IMPORTANT]
> **टेस्ट टोकन — कोई मौद्रिक मूल्य नहीं (TEST TOKENS — NO MONETARY VALUE).** `tANE` एक मुफ़्त, नकली (सिम्युलेटेड) टेस्टनेट टोकन है। इसके पीछे रुपया या कोई भी पैसा नहीं है, इसे भुनाया या बेचा नहीं जा सकता, और यह कभी किसी भविष्य के `ANE` में नहीं बदलेगा। इसे ख़रीदा नहीं जा सकता। कोई भी आपसे इसके लिए पैसे माँगे, तो वह धोखा है।

## आप क्या बनाएँगे

एक AI एजेंट, जिसका अपना बजट है और जो उसे ख़ुद ख़र्च करता है। लगभग पाँच मिनट में आप:

1. फ़ॉसेट (faucet) से मुफ़्त टेस्ट टोकन (`tANE`) लेंगे,
2. उन्हें एक **वॉल्ट (vault)** में रखेंगे और एजेंट को ऐसा बजट देंगे जिसे वह पार नहीं कर सकता,
3. दो **विक्रेता (seller)** एजेंट चलाएँगे, एक TypeScript में और एक Python में, जो दोनों एक छोटी सेवा बेचते हैं,
4. **ख़रीदार (buyer)** एजेंट चलाएँगे, जो दाम पता करते हैं, भुगतान करते हैं और नतीजा पाते हैं,
5. एजेंट का अधिकार वापस लेंगे और बचे हुए टोकन वापस पाएँगे।

बजट की सीमा एक स्मार्ट कॉन्ट्रैक्ट लागू करता है, एजेंट का कोड या कोई प्रॉम्प्ट नहीं। ज़्यादा ख़र्च करने की कोशिश करने वाला एजेंट भी ऐसा नहीं कर सकता।

## "16 आने" क्यों?

1957 में दशमलव प्रणाली आने से पहले एक रुपये में 16 **आने** होते थे: "चार आने" का मतलब था चौथाई रुपया। 16ane यह इकाई **सिर्फ़ उदाहरण के लिए** लेता है। इस सैंडबॉक्स में फ़ॉसेट 16,000 tANE देता है, और यह ₹1,000 या कोई भी रक़म **नहीं** है। टेस्ट टोकन सीखने और बनाने के लिए हैं, और उनकी कोई क़ीमत नहीं है।

## आपको क्या चाहिए

- **Node.js 24 या नया** और **npm**
- **Python 3.11 या नया** (Python एजेंटों के लिए)
- **Foundry** (`anvil`, `forge`, `cast`): देखें [Foundry इंस्टॉल करना](https://book.getfoundry.sh/getting-started/installation)
- **git**

कोई क्रिप्टो वॉलेट, ETH या साइन-अप नहीं चाहिए। नीचे का सब कुछ आपकी अपनी मशीन पर चलता है।

## पाँच मिनट: पूरी यात्रा एक कमांड में

```bash
git clone --recurse-submodules https://github.com/bytesbrains/16ane.git
cd 16ane
npm ci
npm run kit:demo
```

`kit:demo` आपकी मशीन पर एक निजी टेस्ट चेन शुरू करता है और एक मालिक (owner) और एक एजेंट तैयार करता है। फिर वह दोनों विक्रेता शुरू करता है, दोनों ख़रीदारों से भुगतान करवाता है, दिखाता है कि बजट कॉन्ट्रैक्ट ही सँभालता है, और आख़िर में एजेंट का अधिकार वापस लेकर टोकन लौटा देता है। हर क़दम बताता है कि उसने क्या किया। CI यही कमांड चलाता है, और अगर इसमें पाँच मिनट से ज़्यादा लगें तो फ़ेल हो जाता है।

## क़दम-दर-क़दम

तीन टर्मिनल खोलें, सब `16ane` फ़ोल्डर में।

**टर्मिनल 1: लोकल सैंडबॉक्स।** यह Ctrl-C दबाने तक चलता रहता है।

```bash
npm run kit:sandbox
```

**टर्मिनल 2: मालिक (owner)।** ये कमांड सिर्फ़ हस्ताक्षर करती हैं। सैंडबॉक्स इन्हें आगे भेजता है और गैस (gas) का ख़र्च ख़ुद उठाता है।

```bash
npm run kit:owner -- setup     # 16,000 tANE लें, वॉल्ट बनाएँ, उसमें 1,600 डालें, 320 का बजट सौंपें
npm run kit:owner -- status    # वॉल्ट में कितना है और एजेंट अभी कितना ख़र्च कर सकता है
```

**टर्मिनल 3: विक्रेता।**

```bash
npm run kit:seller:ts                            # शब्द गिनती, 16 tANE प्रति कॉल, पोर्ट 9101
python3 examples/hackathon-kit/python/seller.py  # अंकों को देवनागरी में लिखना, 8 tANE प्रति कॉल, पोर्ट 9102
```

हर विक्रेता को अलग टर्मिनल में चलाएँ, या एक को बैकग्राउंड में।

**फिर टर्मिनल 2 में: ख़रीदार।**

```bash
npm run kit:buyer:ts -- http://127.0.0.1:9101/v1/word-count
python3 examples/hackathon-kit/python/buyer.py http://127.0.0.1:9102/v1/digits
npm run kit:owner -- status    # ख़र्च बढ़ा, और बचा हुआ बजट घटा
```

**आख़िर में: अधिकार वापस लें।**

```bash
npm run kit:owner -- revoke     # एजेंट अब ख़र्च नहीं कर सकता
npm run kit:owner -- withdraw   # वॉल्ट के tANE मालिक के पास लौट आते हैं
```

## सार्वजनिक सैंडबॉक्स पर

यही स्क्रिप्ट Base Sepolia टेस्टनेट पर साझा सैंडबॉक्स के साथ भी चलती हैं। वहाँ दूसरे लोगों के बनाए एजेंट आपके एजेंट से ख़रीद सकते हैं।

```bash
npm run kit:owner -- setup --network sandbox
npm run kit:buyer:ts           # https://api.16ane.com पर होस्टेड डेमो API को भुगतान करता है
```

मालिक और ख़रीदार को तब भी ETH नहीं चाहिए, क्योंकि सैंडबॉक्स उनके ट्रांज़ैक्शन भेजता है। सार्वजनिक सैंडबॉक्स पर **विक्रेता** की बात अलग है: भुगतान का सेटलमेंट एक ट्रांज़ैक्शन है। TypeScript विक्रेता यह गैस अपनी कुंजी से देता है, इसलिए वह जो पता छापे, उस पर थोड़ा Base Sepolia ETH भेजें। Python विक्रेता इसके बजाय एक फ़ैसिलिटेटर (facilitator) इस्तेमाल करता है: अपना फ़ैसिलिटेटर चलाएँ ([सेल्फ़-होस्टिंग गाइड](../operations/SELF_HOSTING.md), अंग्रेज़ी में) और `FACILITATOR_URL` सेट करें। फ़ॉसेट पर हर पते के लिए इंतज़ार का समय (cooldown) है। `tANE` को हमेशा [`networks/sandbox-sepolia.json`](../../networks/sandbox-sepolia.json) में दिए कॉन्ट्रैक्ट पते से पहचानें, उसके सिंबल से कभी नहीं।

## सुरक्षित रहें

- किट कुंजियाँ (keys) `examples/hackathon-kit/.kit/` में बनाता है (git इसे अनदेखा करता है, और फ़ाइलें सिर्फ़ आप पढ़ सकते हैं)। कोई कुंजी चैट, प्रॉम्प्ट, स्क्रीनशॉट या issue में कभी न डालें।
- एजेंट को सिर्फ़ उसकी अपनी सेशन कुंजी दें, मालिक की कभी नहीं।
- असली सीमाएँ वॉल्ट की हैं: कुल बजट, प्रति भुगतान सीमा और समय-सीमा (expiry)। ख़रीदारों में `MAX_PAYMENT` आपकी तरफ़ से एक अतिरिक्त सुरक्षा है।
- विक्रेता जो लौटाता है उसे अविश्वसनीय टेक्स्ट मानें, ख़ासकर अगर कोई मॉडल उसे पढ़ता है।

## कुछ गड़बड़ हो तो

| आपको दिखे | यह करें |
|---|---|
| `No network chosen yet` | पहले `npm run kit:sandbox` चलाएँ, या `--network sandbox` इस्तेमाल करें। |
| `anvil: command not found` / `forge: not found` | Foundry इंस्टॉल करें और नया टर्मिनल खोलें। |
| `faucet claim failed (429)` | इस पते ने हाल ही में क्लेम किया है। इंतज़ार करें, या `examples/hackathon-kit/.kit/owner.key` मिटा दें (सिर्फ़ लोकल सैंडबॉक्स में)। |
| `ANE-E-3002` quote exceeds max payment | विक्रेता ख़रीदार के `MAX_PAYMENT` से ज़्यादा माँग रहा है। |
| `ANE-E-3001` insufficient allowance | बजट ख़त्म हो गया या वापस ले लिया गया। `npm run kit:owner -- setup` फिर चलाएँ। |
| लोकल सैंडबॉक्स बंद करने के बाद एरर | दोबारा शुरू करने पर नई चेन बनती है: `npm run kit:owner -- setup` फिर चलाएँ। |
