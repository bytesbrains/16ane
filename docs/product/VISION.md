# Product vision and positioning

## Problem
Agent developers currently stitch together API keys, subscriptions, card billing, provider credits, wallet signing, discovery and manual approval. Autonomous micro-commerce is difficult to demonstrate end-to-end. Providers separately implement trials, quotas and payment integration.

## Mission
Make it trivial to grant an AI agent a bounded crypto budget and let it autonomously buy, deliver, earn and return value across interoperable services.

## Primary users
1. **Agent developer**: fund a bot, connect SDK/MCP, buy a demo API, inspect receipts.
2. **Service developer**: expose priced endpoint, verify payment, meter consumption, issue refunds.
3. **AI lab / API provider**: offer sponsored introductory trials with strict quotas and clear cost attribution.
4. **Educator / hackathon organizer**: distribute faucet allocations, teach commerce, measure task completion.
5. **Wallet owner**: allocate funds, choose fixed/revolving budget, revoke agent, withdraw leftovers.
6. **Future regulated issuer/financial institution**: assess independent real-INR issuance/reserve/redemption module.

## Core jobs to be done
- 'Give my agent an allowance, not my entire treasury.'
- 'Let my agent select intelligence based on cost, latency, and task quality.'
- 'Make my paid API purchasable by any compatible agent.'
- 'Offer free trial usage without creating unlimited real compute liability.'
- 'Let me prove which agent paid, what was delivered, and what remains.'

## Value proposition
- Users: no repeated human approvals within budget; no mandatory separate provider payment account for compatible demo services.
- Providers: open machine-readable pricing, wallet-native checkout, discoverability and controlled trials.
- Ecosystem: portable SDKs, reference contracts, transparent sandbox metrics, self-hostable infrastructure.

## Explicit non-goals
No profit guarantee, speculative token marketing, unrestricted free inference, universal KYC exemption, cross-chain instant finality, automated resolution of subjective service disputes, or implied approval for INR stablecoin issuance. No promise that all merchants accept tANE or that testnet coins buy commercial services outside sponsored offers.

## Product voice
India-first storytelling ('16 Aane = 1 Rupee'), global sandbox access, multilingual guides as capacity allows. Distinguish rupee-denominated **illustrations** from actual monetary value.
