# Roadmap and release gates

## Phase 0 — Discovery and ADRs
Inventory existing 16ane/COPRA repos; confirm brand and ownership; research standards and Indian regulatory boundaries; choose testnet and wallet design; produce threat model and issue graph. **Exit:** accepted ADRs and scoped MVP; no real-money launch.

## Phase 1 — Public sandbox core (P0)
Deploy verified tANE on public testnet, isolated agent wallets and owner delegation, faucet, SDK/CLI, paid HTTP demo, independent payment verification, receipts, documentation and monitoring. **Exit:** repeatable fund -> buy -> sell -> earn -> revoke -> return demo, security tests, public no-value disclosures, and alternate RPC/direct verification.

## Phase 2 — Developer adoption (P1)
Signed service manifests, optional registry/indexer, MCP adapter, provider onboarding, owner dashboard, self-hostable facilitator, sponsored campaigns and quotas. **Exit:** external developer can integrate without operator intervention; hosted services have bounded sponsor costs.

## Phase 3 — Advanced agent economy (P2)
Escrow/milestone settlement, identity/reputation integration, price comparison, provider performance data, interoperability, education/hackathon kits, multi-language India-first documentation. **Exit:** documented independent deployments and resilience tests.

## Parallel track — Real ANE feasibility
Independent legal opinion, institutional discussions, reserve and redemption design, audit/security plan, compliance and governance. **Exit to production only if** authorized structure and all operational/security gates met. This track may remain research indefinitely; public sandbox remains valuable.

## Suggested demo milestones
D1 transfer test token; D2 owner-funded agent purchase; D3 merchant earns; D4 owner withdraws; D5 external provider integrates; D6 sponsored real inference with hard sponsor cost cap.

## Success metrics (never confuse with revenue)
Time to first purchase, SDK integration completion, verified paid demo calls, unique active developer integrations (Sybil-adjusted), successful receipts, payment error rate, wallet security incidents, sponsor real cost, external provider retention, independent infrastructure operators. tANE transaction volume is not economic GDP or fiat revenue.
